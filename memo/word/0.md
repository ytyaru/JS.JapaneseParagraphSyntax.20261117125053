# 2. 「擬識（偽装）」の網羅的分類体系

偽装＝無／有×事実／虚偽＝４通り（無言、隠蔽、虚言、捏造）。

種別|概要
----|----
無言|事実がある。しかしその事実について言及していない。その話題をするにあたって必要な事実確認なのに言及していない。
隠蔽|事実があり事実を隠す意図がある状態。または隠す意図があったとすればそのように記述する理由に筋が通る説明ができる状態。
虚言|事実無根。事実を証明する根拠がない状態。同時に騙す意図も悪意もない状態。
捏造|騙す意図があり事実無根な言及をしている状態。または騙す意図があったとすればそのように記述する理由に筋が通る説明ができる状態。

更に、なぜそれら４通りを行ったか。大本の狙いについては他者支配、他人を操りたいから、という一つの目的に収束する。その手法には洗脳・扇動・宣伝・弁論・論点のすり替え・印象操作など様々な手口がある。

種別|概要

転論は対象が論理であり説明だが、本質について説明せず、「何かを説明した」という説明をしたという事実を作り出し、本質について説明した、という体裁を捏造する行為である。また、内容について、それを証明することに理論上なっていないのに、さもそれが理論上の説明になったかのように言及する隠蔽の一種。隠蔽との違いは隠す対象だ。隠蔽は事実を隠すが、転論は本来説明すべき論点がどこであるかを隠し、それについての説明内容をも隠す。これにて説明しなかった責任も取らずに済み、かつ思い通りの事を非難されずに進めてしまう手口である。
