# AST 構文木

メモリ上に保持するjdの構造を再現できるデータ。その構造を設計する必要がある。

* ASTには実際の文字列を入力せず、原稿の何文字目から何文字目までかの数値だけで部分テキストを抽出する形で参照する（消費メモリ軽減のため）

以下のような構造にすべきかな？

* 原稿（jd形式テキスト文字列）
* Token
    * 種別: p1,p2,br,...
    * 位置: 
        * 開始原稿内index: 0
        * 終了原稿内index: 0
* AST 構文木（AstNode配列）
    * AstNode
        * Token
        * 子Node一覧: []

以下のように、jd原稿、jml、HTMLはASTを介する事で相互変換できる。

* jd原稿→Token→Node(→子Node→子孫Node→...再帰)→AST
* AST→jml,HTML,jd原稿
* jml→DOM→Node→AST→jd原稿
* HTML→DOM→jml化→DOM→Node→AST→jd原稿

これをソースコードに落とし込みたい。
