おっしゃるロジックは、実務のテキスト処理において非常に理にかなった王道の手法です。整理すると、あなたの推測は以下の通りですね。
1. HTML文字参照によるエスケープ手法:
｜《 を先に &#x300A;（や &#12298;）に置換してしまえば、後続の正規表現 /...《...》/ に一切引っかからなくなり、ブラウザ上ではそのまま 《 と表示される。わざわざトークン配列を作って復元処理を書く必要すらない。
2. AST/Token化の不要論:
カクヨムは構文が「ルビ」「傍点」「エスケープ」の3つしかなく、出力先もHTML一択。わざわざ重いASTやトークン化を実装するメリットが薄く、正規表現の連続置換（replace）で直接HTML文字列に変換している可能性が極めて高い。
3. パイプ省略形の開始位置の特定:
パイプなしルビ（漢字《かんじ》）は開始の制御記号がないため、1文字ずつ読むステートマシンでは「漢字が来た時点でルビの親文字になるか先読みし続ける」という無謀な処理になる。結局、正規表現エンジン（バックトラックや文字クラス [一-龠...]+）に任せるのが最も合理的。

HTML文字参照方式で書く場合の厳密な正規表現パイプライン

あなたの推測されたアーキテクチャ（HTML文字参照への退避 ＋ 正規表現の連続置換 ＋ メタ文字の厳密な除外）をそのままコードに落とすと、驚くほどシンプルで堅牢になります。
javascript
function parseKakuyomuDirect(text) {
  return text
    // 1. HTML特殊文字の無害化
    .replace(/&/g, '&amp;')
    .replace(/</g, '&lt;')
    .replace(/>/g, '&gt;')

    // 2. エスケープ処理：｜《 を HTML文字参照 &#x300A; に置換して後続の正規表現から完全に逃がす
    // ※漢字の直後（漢字｜《...》）であっても、ここで &#x300A; に変わるためルビ化しない
    .replace(/[|｜]《/g, '&#x300A;')

    // 3. 傍点：《《...》》 ※内部に 《 や 》 や改行を含まないように制限
    .replace(/《《([^《》\n]+?)》》/g, '<em class="emphasis">$1</em>')

    // 4. パイプありルビ：｜親文字《ルビ》 ※親文字・ルビ共にメタ文字と改行を厳密に除外
    .replace(/[|｜]([^|｜《》\n]+?)《([^《》\n]+?)》/g, '<ruby>$1<rt>$2</rt></ruby>')

    // 5. パイプなしルビ：漢字《ルビ》
    // ※ステップ2で ｜《 が &#x300A; になっているため、漢字｜《...》 はここでは絶対にマッチしない
    .replace(/([一-龠々仝〆〇ヶ]+)《([^《》\n]+?)》/g, '<ruby>$1<rt>$2</rt></ruby>');
}
コードは注意してご使用ください。

この方式（HTML文字参照退避＋正規表現）が優れている理由

• 「漢字｜《ルビにしない》」のバグが構造上起きない
ステップ2の時点で 漢字&#x300A;ルビにしない》 になるため、ステップ5の 漢字《...》 の正規表現が誤爆する余地がゼロになります。
• 後処理（復元ループ）が不要
ブラウザがHTMLをレンダリングする際に &#x300A; を自動的に 《 として描画してくれるため、独自プレースホルダを元に戻す処理すら不要です。
• メタ文字の厳密な除外
[^|｜《》\n]+? を徹底することで、parser.ts のような「別のルビを跨いで誤マッチするバグ」も完全に防げます。
実際のカクヨムのバックエンド（Perl / Go / JS等）でも、構文の少なさとパフォーマンスの観点から、まさにこのように「エスケープ記号を文字参照（または一時コード）へ逃がしてから正規表現で一括置換する」という実装が採られている可能性が非常に高いです。

ご指摘の通りです。2点とも私の正規表現に甘さがありました。

1. ルビ内のパイプ文字 | ｜ の除外漏れ

ルビ側（《...》 の中身）でも、別のルビ開始記号を跨いで誤爆しないよう [^|｜《》\n]+? とすべきでした。
（例：｜親《ルビ1｜親2《ルビ2》 のような不正・未閉じの入力が来たときに、パイプを跨いで吸ってしまうのを防ぐためです）

2. 漢字・踊り字・異体字セレクタの網羅不足

[一-龠々仝〆〇ヶ] は昭和期からよく使われる雑なイディオムであり、現代のUnicode環境では以下の文字がすべて抜け落ちます。
• Unicode漢字ブロックの漏れ: \p{Script=Han}（\p{Han}）を使うことで、CJK統合漢字の拡張A〜I（サロゲートペア領域の漢字）や互換漢字をすべて網羅できます（u フラグ必須）。
• 踊り字・記号類:
	• 々（同の字点）、仝（同上）、〆（しめ）、〇（漢数字のゼロ）、ヶ・ヵ（小書きのケ・カ）※これらは \p{Han} に含まれないものがある（特に 〆 〇 ヶ ヵ）ため明示が必要です。
	• 〻（二の字点：縦書き小説で頻出する漢字の踊り字 \u303B）
• 異体字セレクタ（IVS / SVS）:
	• 漢字の直後に付く \uFE00-\uFE0F（SVS）および \u{E0100}-\u{E01EF}（IVS：サロゲートペア）を含めないと、異体字の途中でマッチが分断されます。

javascript
class Japarser {
  static Options = Object.freeze({
    // 'both' | 'wide' | 'half' または任意のパイプ文字列（例: '|｜'）
    pipe: 'both',
    // 'double-angle' | 'guillemet' または 2文字の開閉括弧（例: '《》'）
    brackets: 'double-angle',
    length: Object.freeze({
      base: 20, // 0なら無制限
      ruby: 50, // 0なら無制限
      em: 0,    // 0なら無制限（公式ヘルプに上限記載なし）
    }),
    // 「漢字1文字分（異体字セレクタ含む）」を表す正規表現パーツ
    kanji: '(?:[\\p{Script=Han}々仝〆〇ヶヵ〻][\\uFE00-\\uFE0F\\u{E0100}-\\u{E01EF}]?)',
  });

  constructor(options = {}) {
    const mergedOptions = {
      ...Japarser.Options,
      ...options,
      length: Object.freeze({
        ...Japarser.Options.length,
        ...(options.length || {}),
      }),
    };

    this._ = {
      options: Object.freeze(mergedOptions),
      regs: Object.freeze(this.#buildRegexps(mergedOptions)),
    };
  }

  get options() {
    return this._.options;
  }

  get regs() {
    return this._.regs;
  }

  #buildRegexps(opts) {
    // 1. パイプ文字の解決
    const pipeMap = {
      both: '|｜',
      wide: '｜',
      half: '|',
    };
    const rawPipes = pipeMap[opts.pipe] ?? opts.pipe;
    const escapedPipes = this.#escapeRegExpClass(rawPipes);
    const pipePattern = `[${escapedPipes}]`;

    // 2. 括弧の解決
    const bracketMap = {
      'double-angle': ['《', '》'],
      guillemet: ['«', '»'],
    };
    const [openBr, closeBr] = Array.isArray(opts.brackets)
      ? opts.brackets
      : bracketMap[opts.brackets] ?? [...opts.brackets];

    const escOpen = this.#escapeRegExp(openBr);
    const escClose = this.#escapeRegExp(closeBr);
    const excludedChars = `${escapedPipes}${this.#escapeRegExpClass(openBr + closeBr)}\\n`;

    // 3. 量指定子（字数制限）の生成
    const qBase = opts.length.base > 0 ? `{1,${opts.length.base}}` : '+';
    const qRuby = opts.length.ruby > 0 ? `{1,${opts.length.ruby}}` : '+';
    const qEm = opts.length.em > 0 ? `{1,${opts.length.em}}` : '+';

    // 4. 各パーツの組み立て
    const baseText = `([^${excludedChars}]${qBase})`;
    const rubyText = `([^${excludedChars}]${qRuby})`;
    const emText = `([^${excludedChars}]${qEm})`;
    const kanjiBase = `(${opts.kanji}${qBase})`;

    // 開き括弧の数値文字参照（エスケープ退避用）
    const openEntity = `&#x${openBr.codePointAt(0).toString(16).toUpperCase().padStart(4, '0')};`;

    return {
      openEntity,
      escape: new RegExp(`${pipePattern}${escOpen}`, 'gu'),
      emphasis: new RegExp(`${escOpen}{2}${emText}${escClose}{2}`, 'gu'),
      rubyWithPipe: new RegExp(`${pipePattern}${baseText}${escOpen}${rubyText}${escClose}`, 'gu'),
      rubyWithoutPipe: new RegExp(`${kanjiBase}${escOpen}${rubyText}${escClose}`, 'gu'),
    };
  }

  // 正規表現の通常コンテキスト用エスケープ
  #escapeRegExp(str) {
    return str.replace(/[.*+?^${}()|[\]\\]/g, '\\$&');
  }

  // 正規表現の文字クラス [...] 内部用エスケープ
  #escapeRegExpClass(str) {
    return str.replace(/[\\\]^-]/g, '\\$&');
  }

  parse(text) {
    const { regs } = this._;
    return text
      .replace(/&/g, '&amp;')
      .replace(/</g, '&lt;')
      .replace(/>/g, '&gt;')
      .replace(regs.escape, regs.openEntity)
      .replace(regs.emphasis, '<em class="emphasis">$1</em>')
      .replace(regs.rubyWithPipe, '<ruby>$1<rt>$2</rt></ruby>')
      .replace(regs.rubyWithoutPipe, '<ruby>$1<rt>$2</rt></ruby>');
  }
}

 * Japarser の初期化（オプション設定）時の例外
 */
class JaparserNewError extends Error {
  constructor(message) {
    super(message);
    this.name = 'JaparserNewError';
  }
}

/**
 * Japarser.prototype.parse() 実行時の例外

class JaparserParseError extends Error {
  constructor(message) {

class Japarser {
  static DefaultLength = Object.freeze({
    rb: 20, // 親文字の最大文字数（0は無制限）
    rt: 50, // ルビ文字の最大文字数（0は無制限）
    em: 0,  // 傍点文字の最大文字数（0は無制限）
  });

  static DefaultKanji = '(?:[\\p{Script=Han}々仝〆〇ヶヵ〻][\\uFE00-\\uFE0F\\u{E0100}-\\u{E01EF}]?)';

  static Presets = Object.freeze({
    // カクヨム準拠仕様
    KAKUYOMU: Object.freeze({
      pipes: '|｜',
      brackets: '《》',
      length: Japarser.DefaultLength,
      kanji: Japarser.DefaultKanji,
    }),
    // 合理的仕様（全角パイプのみ・ギュメ括弧）
    RATIONAL: Object.freeze({
      pipes: '｜',
      brackets: '«»',
      length: Japarser.DefaultLength,
      kanji: Japarser.DefaultKanji,
    }),
  });

  static Options = Japarser.Presets.KAKUYOMU;

  constructor(options = {}) {
    if (options === null || typeof options !== 'object' || Array.isArray(options)) {
      throw new JaparserNewError(
        'オプションはオブジェクト形式で指定してください。例: new Japarser({ pipes: "｜", brackets: "«»" })'
      );
    }

    const mergedOptions = {
      ...Japarser.Options,
      ...options,
      length: Object.freeze({
        ...Japarser.DefaultLength,
        ...(options.length ?? {}),
      }),
    };

    this.#validateOptions(mergedOptions);

    this._ = Object.freeze({
      options: Object.freeze(mergedOptions),
      regs: Object.freeze(this.#buildRegexps(mergedOptions)),
    });
  }

  get options() {
    return this._.options;
  }

  get regs() {
    return this._.regs;
  }

  #validateOptions(opts) {
    // 1. pipes の検証
    if (typeof opts.pipes !== 'string' || [...opts.pipes].length === 0) {
      throw new JaparserNewError(
        'options.pipes は1文字以上の文字列で指定してください。ルビの親文字開始やエスケープに使う縦線記号の候補を表します。例: "｜" や "|｜"'
      );
    }

    // 2. brackets の検証
    if (typeof opts.brackets !== 'string') {
      throw new JaparserNewError(
        'options.brackets は2文字の文字列で指定してください。1文字目が開き括弧、2文字目が閉じ括弧になります。例: "《》" や "«»"'
      );
    }
    const bracketChars = [...opts.brackets];
    if (bracketChars.length !== 2) {
      throw new JaparserNewError(
        `options.brackets は厳密に2文字の文字列で指定してください（現在 ${bracketChars.length} 文字です）。1文字目が開始、2文字目が終了を表します。例: "《》" や "«»"`
      );
    }
    if (bracketChars[0] === bracketChars[1]) {
      throw new JaparserNewError(
        `options.brackets の開始文字と終了文字に同じ文字（"${bracketChars[0]}"）は指定できません。傍点の二重括弧の開閉が判別できなくなるためです。例: "《》" や "«»"`
      );
    }

    // 3. pipes と brackets の文字重複検証
    const pipeSet = new Set([...opts.pipes]);
    for (const bChar of bracketChars) {
      if (pipeSet.has(bChar)) {
        throw new JaparserNewError(
          `options.pipes と options.brackets に同じ文字（"${bChar}"）が含まれています。構文の開始・終了・エスケープが判別不能になるため、異なる記号を指定してください。例: { pipes: "｜", brackets: "«»" }`
        );
      }
    }

    // 4. length の検証
    if (opts.length === null || typeof opts.length !== 'object' || Array.isArray(opts.length)) {
      throw new JaparserNewError(
        'options.length はオブジェクト形式で指定してください。例: { rb: 20, rt: 50, em: 0 }'
      );
    }
    for (const key of ['rb', 'rt', 'em']) {
      const val = opts.length[key];
      if (typeof val !== 'number' || !Number.isInteger(val) || val < 0) {
        throw new JaparserNewError(
          `options.length.${key} は0以上の整数で指定してください（0は無制限を表します）。例: { rb: 20, rt: 50, em: 0 }`
        );
      }
    }

    // 5. kanji の検証
    if (typeof opts.kanji !== 'string' || opts.kanji.length === 0) {
      throw new JaparserNewError(
        'options.kanji はパイプ省略時の親文字（漢字1文字分）を表す正規表現文字列で指定してください。例: "[一-龠々仝〆〇ヶ]"'
      );
    }
    try {
      new RegExp(opts.kanji, 'u');
    } catch (e) {
      throw new JaparserNewError(
        `options.kanji に指定された正規表現パターンが不正です（${e.message}）。有効な正規表現文字列を指定してください。例: "[一-龠々仝〆〇ヶ]"`
      );
    }
  }

  #buildRegexps(opts) {
    const escapedPipes = this.#escapeRegExpClass(opts.pipes);
    const pipePattern = `[${escapedPipes}]`;

    const [openBr, closeBr] = [...opts.brackets];
    const escOpen = this.#escapeRegExp(openBr);
    const escClose = this.#escapeRegExp(closeBr);
    const excludedChars = `${escapedPipes}${this.#escapeRegExpClass(openBr + closeBr)}\\n`;

    const qRb = opts.length.rb > 0 ? `{1,${opts.length.rb}}` : '+';
    const qRt = opts.length.rt > 0 ? `{1,${opts.length.rt}}` : '+';
    const qEm = opts.length.em > 0 ? `{1,${opts.length.em}}` : '+';

    const rbText = `([^${excludedChars}]${qRb})`;
    const rtText = `([^${excludedChars}]${qRt})`;
    const emText = `([^${excludedChars}]${qEm})`;
    const kanjiBase = `(${opts.kanji}${qRb})`;

    const openEntity = `&#x${openBr.codePointAt(0).toString(16).toUpperCase().padStart(4, '0')};`;

    return {
      openEntity,
      escape: new RegExp(`${pipePattern}${escOpen}`, 'gu'),
      emphasis: new RegExp(`${escOpen}{2}${emText}${escClose}{2}`, 'gu'),
      rubyWithPipe: new RegExp(`${pipePattern}${rbText}${escOpen}${rtText}${escClose}`, 'gu'),
      rubyWithoutPipe: new RegExp(`${kanjiBase}${escOpen}${rtText}${escClose}`, 'gu'),
    };
  }

  #escapeRegExp(str) {
    return str.replace(/[.*+?^${}()|[\]\\]/g, '\\$&');
  }

  #escapeRegExpClass(str) {
    return str.replace(/[\\\]^-]/g, '\\$&');
  }

  parse(text) {
    if (typeof text !== 'string') {
      throw new JaparserParseError(
        `parse() の引数は文字列（string）である必要があります（受け取った型: ${text === null ? 'null' : typeof text}）。`
      );
    }

    const { regs } = this._;
    return text
      .replace(/&/g, '&amp;')
      .replace(/</g, '&lt;')
      .replace(/>/g, '&gt;')
      .replace(regs.escape, regs.openEntity)
      .replace(regs.emphasis, '<em class="emphasis">$1</em>')
      .replace(regs.rubyWithPipe, '<ruby>$1<rt>$2</rt></ruby>')
      .replace(regs.rubyWithoutPipe, '<ruby>$1<rt>$2</rt></ruby>');
  }
}

class JsyntaxError extends Error {

 */
class JparseError extends Error {
  constructor(message) {
    super(message);
    this.name = 'JparseError';
  }
}

/**
 * 構文の検証と正規表現のコンパイル・保持を担うクラス
 */
class Jsyntax {
  static DefaultLength = Object.freeze({
    rb: 20, // 親文字の最大文字数（0は無制限）
    rt: 50, // ルビ文字の最大文字数（0は無制限）
    em: 0,  // 傍点文字の最大文字数（0は無制限）
  });

  static DefaultKanji = '(?:[\\p{Script=Han}々仝〆〇ヶヵ〻][\\uFE00-\\uFE0F\\u{E0100}-\\u{E01EF}]?)';

  static #defaultInstance = null;
  static #kakuyomuInstance = null;

  // 合理的仕様（全角パイプのみ・ギュメ括弧）
  static get default() {
    if (!this.#defaultInstance) {
      this.#defaultInstance = new Jsyntax({
        pipes: '｜',
        brackets: '«»',
      });
    }
    return this.#defaultInstance;
  }

  // カクヨム準拠仕様（半角全角パイプ・二重山括弧）
  static get kakuyomu() {
    if (!this.#kakuyomuInstance) {
      this.#kakuyomuInstance = new Jsyntax({
        pipes: '|｜',
        brackets: '《》',
      });
    }
    return this.#kakuyomuInstance;
  }

  constructor(options = {}) {
    if (options === null || typeof options !== 'object' || Array.isArray(options)) {
      throw new JsyntaxError(
        'オプションはオブジェクト形式で指定してください。例: new Jsyntax({ pipes: "｜", brackets: "«»" })'
      );
    }

    const mergedOptions = {
      pipes: '｜',
      brackets: '«»',
      kanji: Jsyntax.DefaultKanji,
      ...options,
      length: Object.freeze({
        ...Jsyntax.DefaultLength,
        ...(options.length ?? {}),
      }),
    };

    this.#validate(mergedOptions);

    this._ = Object.freeze({
      options: Object.freeze(mergedOptions),
      regs: Object.freeze(this.#buildRegexps(mergedOptions)),
    });
  }

  get options() {
    return this._.options;
  }

  get regs() {
    return this._.regs;
  }

  #validate(opts) {
    // 1. pipes
    if (typeof opts.pipes !== 'string' || [...opts.pipes].length === 0) {
      throw new JsyntaxError(
        'options.pipes は1文字以上の文字列で指定してください。例: "｜" や "|｜"'
      );
    }

    // 2. brackets
    if (typeof opts.brackets !== 'string') {
      throw new JsyntaxError(
        'options.brackets は2文字の文字列で指定してください。例: "《》" や "«»"'
      );
    }
    const bracketChars = [...opts.brackets];
    if (bracketChars.length !== 2) {
      throw new JsyntaxError(
        `options.brackets は厳密に2文字の文字列で指定してください（現在 ${bracketChars.length} 文字）。例: "《》" や "«»"`
      );
    }
    if (bracketChars === bracketChars) {
      throw new JsyntaxError(
        `options.brackets の開始文字と終了文字に同じ文字（"${bracketChars}"）は指定できません。例: "《》" や "«»"`
      );
    }

    // 3. pipes と brackets の重複チェック
    const pipeSet = new Set([...opts.pipes]);
    for (const bChar of bracketChars) {
      if (pipeSet.has(bChar)) {
        throw new JsyntaxError(
          `options.pipes と options.brackets に同じ文字（"${bChar}"）が含まれています。異なる記号を指定してください。`
        );
      }
    }

    // 4. length
    if (opts.length === null || typeof opts.length !== 'object' || Array.isArray(opts.length)) {
      throw new JsyntaxError(
        'options.length はオブジェクト形式で指定してください。例: { rb: 20, rt: 50, em: 0 }'
      );
    }
    for (const key of ['rb', 'rt', 'em']) {
      const val = opts.length[key];
      if (typeof val !== 'number' || !Number.isInteger(val) || val < 0) {
        throw new JsyntaxError(
          `options.length.${key} は0以上の整数で指定してください（0は無制限）。例: { rb: 20, rt: 50, em: 0 }`
        );
      }
    }

    // 5. kanji
    if (typeof opts.kanji !== 'string' || opts.kanji.length === 0) {
      throw new JsyntaxError(
        'options.kanji は漢字1文字分を表す正規表現文字列で指定してください。例: "[一-龠々仝〆〇ヶ]"'
      );
    }
    try {
      new RegExp(opts.kanji, 'u');
    } catch (e) {
      throw new JsyntaxError(
        `options.kanji の正規表現が不正です（${e.message}）。例: "[一-龠々仝〆〇ヶ]"`
      );
    }
  }

  #buildRegexps(opts) {
    const escapedPipes = this.#escapeRegExpClass(opts.pipes);
    const pipePattern = `[${escapedPipes}]`;

    const [openBr, closeBr] = [...opts.brackets];
    const escOpen = this.#escapeRegExp(openBr);
    const escClose = this.#escapeRegExp(closeBr);
    const excludedChars = `${escapedPipes}${this.#escapeRegExpClass(openBr + closeBr)}\\n`;

    const qRb = opts.length.rb > 0 ? `{1,${opts.length.rb}}` : '+';
    const qRt = opts.length.rt > 0 ? `{1,${opts.length.rt}}` : '+';
    const qEm = opts.length.em > 0 ? `{1,${opts.length.em}}` : '+';

    const rbText = `([^${excludedChars}]${qRb})`;
    const rtText = `([^${excludedChars}]${qRt})`;
    const emText = `([^${excludedChars}]${qEm})`;
    const kanjiBase = `(${opts.kanji}${qRb})`;

    const openEntity = `&#x${openBr.codePointAt(0).toString(16).toUpperCase().padStart(4, '0')};`;

    return {
      openEntity,
      escape: new RegExp(`${pipePattern}${escOpen}`, 'gu'),
      emphasis: new RegExp(`${escOpen}{2}${emText}${escClose}{2}`, 'gu'),
      rubyWithPipe: new RegExp(`${pipePattern}${rbText}${escOpen}${rtText}${escClose}`, 'gu'),
      rubyWithoutPipe: new RegExp(`${kanjiBase}${escOpen}${rtText}${escClose}`, 'gu'),
    };
  }

  #escapeRegExp(str) {
    return str.replace(/[.*+?^${}()|[\]\\]/g, '\\$&');
  }

  #escapeRegExpClass(str) {
    return str.replace(/[\\\]^-]/g, '\\$&');
  }
}

/**
 * テキストをHTMLに変換する純粋関数
 */
function jparse(text, syntax = Jsyntax.default) {
  if (typeof text !== 'string') {
    throw new JparseError(
      `第1引数 text は文字列（string）である必要があります（受け取った型: ${text === null ? 'null' : typeof text}）。`
    );
  }
  if (!(syntax instanceof Jsyntax)) {
    throw new JparseError(
      '第2引数 syntax は Jsyntax のインスタンスである必要があります。例: jparse(text, Jsyntax.kakuyomu)'
    );
  }

  const { regs } = syntax;
  return text
    .replace(/&/g, '&amp;')
    .replace(/</g, '&lt;')
    .replace(/>/g, '&gt;')
    .replace(regs.escape, regs.openEntity)
    .replace(regs.emphasis, '<em class="emphasis">$1</em>')
    .replace(regs.rubyWithPipe, '<ruby>$1<rt>$2</rt></ruby>')
    .replace(regs.rubyWithoutPipe, '<ruby>$1<rt>$2</rt></ruby>');
}

          `options.length.${key} は0以上の整数で指定してください（0は無制限）。例: { rb: 20, rt: 50, em: 0 }`
        );
      }
    }

    // 5. kanji
    if (typeof opts.kanji !== 'string' || opts.kanji.length === 0) {
      throw new JsyntaxError(
        'options.kanji は漢字1文字分を表す正規表現文字列で指定してください。例: "[一-龠々仝〆〇ヶ]"'
      );
    }
    try {
      new RegExp(opts.kanji, 'u');
    } catch (e) {
      throw new JsyntaxError(
        `options.kanji の正規表現が不正です（${e.message}）。例: "[一-龠々仝〆〇ヶ]"`
      );
    }
  }

  #buildRegexps(opts) {
    const escapedPipes = this.#escapeRegExpClass(opts.pipes);
    const pipePattern = `[${escapedPipes}]`;

    const [openBr, closeBr] = [...opts.brackets];
    const escOpen = this.#escapeRegExp(openBr);
    const escClose = this.#escapeRegExp(closeBr);
    const excludedChars = `${escapedPipes}${this.#escapeRegExpClass(openBr + closeBr)}\\n`;

    const qRb = opts.length.rb > 0 ? `{1,${opts.length.rb}}` : '+';
    const qRt = opts.length.rt > 0 ? `{1,${opts.length.rt}}` : '+';
    const qEm = opts.length.em > 0 ? `{1,${opts.length.em}}` : '+';

    const rbText = `([^${excludedChars}]${qRb})`;
    const rtText = `([^${excludedChars}]${qRt})`;
    const emText = `([^${excludedChars}]${qEm})`;
    const kanjiBase = `(${opts.kanji}${qRb})`;

    const openEntity = `&#x${openBr.codePointAt(0).toString(16).toUpperCase().padStart(4, '0')};`;

    return {
      openEntity,
      escape: new RegExp(`${pipePattern}${escOpen}`, 'gu'),
      emphasis: new RegExp(`${escOpen}{2}${emText}${escClose}{2}`, 'gu'),
      rubyWithPipe: new RegExp(`${pipePattern}${rbText}${escOpen}${rtText}${escClose}`, 'gu'),
      rubyWithoutPipe: new RegExp(`${kanjiBase}${escOpen}${rtText}${escClose}`, 'gu'),
    };
  }

  #escapeRegExp(str) {
    return str.replace(/[.*+?^${}()|[\]\\]/g, '\\$&');
  }

  #escapeRegExpClass(str) {
    return str.replace(/[\\\]^-]/g, '\\$&');
  }
}

/**
 * テキストをHTMLに変換する純粋関数
 */
function jparse(text, syntax = Jsyntax.default) {
  if (typeof text !== 'string') {
    throw new JparseError(
      `第1引数 text は文字列（string）である必要があります（受け取った型: ${text === null ? 'null' : typeof text}）。`
    );
  }
  if (!(syntax instanceof Jsyntax)) {
    throw new JparseError(
      '第2引数 syntax は Jsyntax のインスタンスである必要があります。例: jparse(text, Jsyntax.kakuyomu)'
    );
  }

  const { regs } = syntax;
  return text
    .replace(/&/g, '&amp;')
    .replace(/</g, '&lt;')
    .replace(/>/g, '&gt;')
    .replace(regs.escape, regs.openEntity)
    .replace(regs.emphasis, '<em class="emphasis">$1</em>')
    .replace(regs.rubyWithPipe, '<ruby>$1<rt>$2</rt></ruby>')
    .replace(regs.rubyWithoutPipe, '<ruby>$1<rt>$2</rt></ruby>');
}
