段落分けする簡易構文パーサを書いてくれ。

日本語文章は英語圏と違い、段落が二つある。それを改行コードの個数で表現できるようにする構文だ。

また、日本語Web小説には段落間改行がある。敢えて段落間に無駄な空行を表示する奴だ。あれも設定次第で表現できるようにしたい。

* 改行1個: 意味段落内改行（形式段落）
* 改行2個: 意味段落分割
* 改行3個以上: 意味段落間改行（N-2個（N>2））

# 簡易構文

```markdown
意味段落１中形式段落１。
意味段落１中形式段落２。

意味段落２中形式段落１。
意味段落２中形式段落２。


意味段落３中形式段落１。
意味段落３中形式段落２。



意味段落４中形式段落１。
意味段落４中形式段落２。
```

# 実装

```javascript
const syntax = new JparaSyntax({
    br: true/false, // 段落間改行の有無。デフォルトは有りtrue。
    indexnt: true/false, // 形式段落ごとに先頭に全角スペースを入れるか否か。デフォルトはfalse。
});
JparaSyntax.default; // {br:true, indexnt:false} の設定インスタンス
const html = jpara(原稿, syntax); // syntaxを省略したらJparaSyntax.defaultであるものとする。
```

# 設定結果例

```javascript
const html = jpara(原稿, new JparaSyntax({
    br: true, // 段落間改行の有無。デフォルトは有りtrue。
    indexnt: true, // 形式段落ごとに先頭に全角スペースを入れるか否か。デフォルトはfalse。
}));
```
```markdown
意味段落１。


意味段落２中形式段落１。
意味段落２中形式段落１。
```

```html
</p>
```

# 懸念
