段落分けする簡易構文パーサを書いてくれ。

日本語文章は英語圏と違い、段落が二つある。それを改行コードの個数で表現できるようにする構文だ。

また、日本語Web小説には段落間改行がある。敢えて段落間に無駄な空行を表示する奴だ。あれも設定次第で表現できるようにしたい。

* 改行1個: 意味段落内改行（形式段落）
* 改行2個: 意味段落分割
* 改行3個以上: 意味段落間改行（N-2個（N>2））

# 簡易構文

```markdown
意味段落１中形式段落１。
意味段落１中形式段落２。

意味段落２中形式段落１。
意味段落２中形式段落２。


意味段落３中形式段落１。
意味段落３中形式段落２。



意味段落４中形式段落１。
意味段落４中形式段落２。
```

# 実装

```javascript
const syntax = new JparaSyntax({
    br: true/false, // 段落間改行の有無。デフォルトは有りtrue。
    indent: true/false, // 形式段落ごとに先頭に全角スペースを入れるか否か。デフォルトはfalse。
});
JparaSyntax.default; // {br:true, indent:false} の設定インスタンス
const html = jpara(原稿, syntax); // syntaxを省略したらJparaSyntax.defaultであるものとする。
```

# 解答

```javascript
class JparaSyntax {
  constructor(options = {}) {
    this.br = options.br !== undefined ? Boolean(options.br) : true;
    this.indent = options.indent !== undefined ? Boolean(options.indent) : false;
  }

  static get default() {
    return new JparaSyntax({ br: true, indent: false });
  }
}

function jpara(text, syntax = JparaSyntax.default) {
  if (!text) return '';

  // 改行コードを \n に正規化し、前後の余分な空行をトリム
  const normalized = text.replace(/\r\n?/g, '\n').replace(/^\n+|\n+$/g, '');
  if (!normalized) return '';

  // 2個以上の連続する改行をキャプチャして分割
  const tokens = normalized.split(/(\n{2,})/);
  const result = [];

  for (let i = 0; i < tokens.length; i++) {
    const token = tokens[i];

    if (i % 2 === 0) {
      // 【意味段落】の処理（単一改行で形式段落に分割）
      const formalParas = token.split('\n').map(line => {
        if (!syntax.indent) return line;
        return line.startsWith('　') ? line : '　' + line;
      });
      result.push(`<p>${formalParas.join('<br>')}</p>`);
    } else {
      // 【意味段落間の改行】の処理
      if (syntax.br) {
        const newlineCount = token.length;
        if (newlineCount > 2) {
          result.push('<br>'.repeat(newlineCount - 2));
        }
      }
    }
  }

  return result.join('\n');
}
```
