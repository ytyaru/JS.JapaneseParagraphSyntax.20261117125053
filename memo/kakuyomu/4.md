* Unicodeであること
* 全テキストをトリムする（冒頭・末尾にある空白文字を全削除する）
* 改行コード`\r\n`,`\r`は全て`\n`に置換する
* HTMLサニタイズする

```javascript
function trim(text) {return text.trim();}
```
```javascript
function normalizeNewline(text) {return text.replace(/\r\n|\r/g, '\n);}
```
```javascript
function escapeHtml(str) {
  const map = {
    "&": "&amp;",
    "<": "&lt;",
    ">": "&gt;",
    '"': "&quot;",
    "'": "&#39;",
  };
  return String(str).replace(/[&<>"']/g, (char) => map[char]);
}
```
