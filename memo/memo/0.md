# 4. 「表の中に表」と循環参照（依存関係）の解決

> これを実現し、かつ無限ループ（表Aが表Bを呼び、表Bが表Aを呼ぶ状態）を防ぐには、パーサーの設計に「DAG（有向非巡回グラフ）の解決」というシンプルなアルゴリズムを組み込みます。

めちゃ大変そうだなぁ。どのみちこの依存関係の解決は必要だ。

全部単一ファイル内にあるテキストとして表現できない。それは構文の規格として如何なものか。その識別子が存在するか否かとか循環参照しないかだとかを判断するためにファイルシステムからファイルを読み取る必要があるのだから。テキスト内の記述だけでは完結できない。

その代わり、列の値に画像を入れたい時なども同様の方法で参照できる強みがある。しかもそれは各ファイル個別のpngだのmp3だのmdだのという異なる形式のままだ。
